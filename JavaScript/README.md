# JavaScript

Client-side JavaScript for model-driven Power Apps / Dynamics 365 CE.

## Topics
- Form events
- Fields and controls
- Lookup filtering
- Lookup custom views
- Web API CRUD
- Paging and filtering
- Notifications
- Tabs and sections
- Subgrids and grids
- Ribbon / Command Bar
- Display and Enable rules
- BPF
- Navigation and dialogs
- Associate / disassociate
- Custom API execution
- Security and user context
- High-volume product filtering

The examples use formContext and Xrm.WebApi and are written as reusable functions rather than one-off snippets.
