# Security

Dynamics 365 / Dataverse security model notes and practical checks.

## Topics
- Business units
- Security roles
- Privileges and access levels
- Teams and ownership
- Owner teams vs access teams
- Field security profiles
- Sharing
- Hierarchical security
- Record ownership
- User context in JavaScript
- Server-side security expectations
- Troubleshooting access issues

The goal is to explain what controls access, where to investigate, and how to avoid relying on client-side security checks alone.
