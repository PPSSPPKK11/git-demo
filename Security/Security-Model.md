# Security Model

## Core areas

Business Unit
→ Security Role
→ Privileges
→ Access Level
→ Ownership / Team
→ Record access

Also consider:
- Field Security Profiles
- Sharing
- Hierarchical security
- Access teams
- Owner teams

## Troubleshooting order

1. Confirm the user is enabled and belongs to the expected business unit/team.
2. Check security roles.
3. Check the required privilege and access level.
4. Check record ownership.
5. Check team membership.
6. Check sharing or access-team access.
7. Check field security if the record is visible but a field is not.

Client-side JavaScript can improve the user experience but should not be treated as the security boundary.
