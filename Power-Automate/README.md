# Power Automate

Reusable Power Automate patterns from Dynamics 365 / Dataverse projects.

## Topics
- Dataverse triggers
- Child flows
- Failure logging
- SharePoint-based error reporting
- Environment variables
- Connection references
- Service accounts
- Previous-business-day reporting
- Monday-Friday scheduling
- Lookup handling
- Related vs unrelated rows
- Bound vs unbound actions

## Practical scenarios
- Log failed flows into SharePoint and send a consolidated report.
- Pick only the previous business day's failures.
- Keep site/list configuration environment-specific.
- Use child flows for reusable failure handling.
