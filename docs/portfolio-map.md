# Portfolio Map

This repository is intentionally built as a working reference for Dynamics 365 CE / Power Platform engineering.

## Core CRM

- Opportunity lifecycle and close controls
- Quote / Order / Invoice / Payment dependencies
- Product selection and heat-outcome processing
- Business Process Flow diagnostics
- Security/context and ownership validation

## Client API

- Forms and field state
- Lookups and custom views
- Subgrids and grids
- Ribbon/command bar
- Web API
- BPF
- Navigation/dialogs
- Relationship operations
- Custom APIs

## Automation

- Failure logging
- Previous-business-day reporting
- Environment variables
- Connection references
- Child/master flow design
- Customer Insights - Journeys triggers and segmentation

## Engineering quality

- Registration matrices
- Tests
- Tracing
- Configuration
- Performance notes
- ALM
- Architecture decisions
- Incident/debugging notes

The repository deliberately includes real-world edges—transaction rollback, environment differences, duplicate form initialization and filter precedence—because those are the parts that demonstrate engineering judgement.
